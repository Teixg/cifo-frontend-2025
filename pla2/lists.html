LLISTES

Tipus de llistes

Podem diferenciar 3 tipus de llistes, les no ordenades amb la etiquetas <ul>, les ordenades amb la etiqueta <ol> y de descripció <dl>

Les llistes <ul> tenen la següent jerarquia:

<ul>
<li> Element 1</li>
<li> Element 2</li>
<li> Element 3</li>
</ul>

On es pot veure que s'empra el <ul> per crear la llista i <li> per encapsular cada element de la llista

Un exemple es el llistat del Index

Les llistes <ol> tenen la següent jerarquia:

<ol>
<li> Element 1</li>
<li> Element 2</li>
<li> Element 3</li>
</ol>

En aquest cas s'utilitza <ol> per crear la llista i <li> per encapsular cada element de la llista com a la llista no ordenada

Un exemple:

Les etiquetes mes importants del PLA 2

  1. <h1>
  2. <p>
  3. <img>
  4. <a>
  5. <ul>
  6. <ol>
  7. <table>
  8. <input>
  9. <nav>
  10. <div>

Per últim les llistes <dl> tenen la següent jerarquia:

<dl>
<dt> Element 1</dt>
<dd> Descripció 1</dd>
<dt> Element 2</dt>
<dd> Descripció 2</dd>
</ol>

Un exemple:

Element 1
Descripció del element 1 que en aquest cas és només un text d'exemple
Element 2
Descripció del element 2 que en aquest cas és només un text d'exemple
Element 3
Descripció del element 3 que en aquest cas és només un text d'exemple
Element 4
Descripció del element 4 que en aquest cas és només un text d'exemple
