1. Spread, rest i destructuring objects

Expliqueu de manera entenedora per què es produeix aquest error...

El problema surt perquè la funció chooseBetween() espera dos objectes, però a la crida se li passa l’array sencer. Això fa que un paràmetre sigui un array i l’altre sigui undefined. Quan intenta accedir a .name, unes vegades surt undefined i altres vegades dóna error, depenent de quin paràmetre agafi el Math.random(). La solució és passar-li dos objectes en lloc de l’array.

Quin mecanisme s'està aplicant a les dues primeres línies?

fan servir destructuring. El primer cas és array destructuring: assigna cada element de l’array artists a les variables a1, a2 i a3. El segon cas és object destructuring: extreu les propietats name i art de l’objecte a2 i les guarda en variables amb aquests noms.
